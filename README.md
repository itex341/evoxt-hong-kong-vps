## 香港节点到底走什么线路？

这是搜"香港服务器推荐"的人最容易踩空的地方。同样标"香港"，线路差别能决定你国内用户打开页面是 40ms 还是 150ms 以上。

行业内大致分三档：

- **精品 BGP**：电信、联通回程都走 CU，移动回程走 CMI，三网都上骨干直连，晚高峰波动小。适合用户几乎全在国内、对延迟敏感的业务。
- **优质 BGP**：电信回程 CMI，联通回程在 CU、NTT、CMI 之间均衡，移动回程 Level3，国际方向择优选路。三网都能用，同时兼顾海外。
- **国际 BGP**：不含 CMI、CU 优化，国际方向择优选路。面向东南亚、欧美的跨境独立站合适，国内访问延迟明显更高。

判断规则很简单：主力用户在国内，就必须确认有 CN2、CMI 或 CU 的回程优化，否则国内访问延迟能到 150ms 以上；纯出海业务，国际 BGP 反而更划算，因为省下的线路成本可以换成更大的带宽。

Evoxt 香港节点的情况，官方没有在主推页面上强调中国大陆优化线路，卖点是高频 CPU、NVMe 和 1Gbps 端口。第三方测评机构对香港节点做过 traceroute，路由显示上游为 xtom（AS9312），去程经中国移动 AS58453 出口，回程到广州电信约 86ms、到北京约 83ms。这个数字说明它属于国际方向择优选路的类型，不是 CN2 GIA 那种三网直连档位。该测评给出的香港测试 IP 是 166.88.77.8，可以自己 ping 一遍看本地延迟和丢包。第三方数据有时效性，最终以你实测为准。
